# Ease Chequ — Admin Documentation

Этот раздел документации описывает административную панель проекта **Ease Chequ**.  
Он состоит из двух основных документов:

- [`FILES_ADMIN.md`](./FILES_ADMIN.md) — структура файлов, назначение, операционные правила.  
- [`DESIGN_ADMIN.md`](./DESIGN_ADMIN.md) — дизайн, UI‑логика, статус реализации (MVP / будущее).  

---

## 📂 Структура админки
- **Dashboard** — ключевые метрики.  
- **Agents** — управление агентами (CRUD, Access until, Invite‑ссылки, архивирование).  
- **Clients** — клиенты, привязанные к агентам (моки, CRUD в будущем).  
- **Requests** — заявки (Pending → Approve/Reject → Archive).  
- **Archive** — удалённые агенты и архивные заявки.  
- **Logs** — аудит действий, пагинация, экспорт CSV.  
- **Access** — управление ролями (Super Admin, Admin, Viewer).  
- **Settings** — конфигурация (будущее: биллинг, email, webhooks).  

---

## 🔑 Основные правила
- Удаление = архивирование.  
- Requests показывают только Pending; Approved/Rejected → Archive.  
- Invite‑ссылка = одноразовый токен для первого входа.  
- Viewer = read‑only.  
- Все действия логируются.  

---

## 📝 Статус реализации
- ✅ Реализовано: CRUD агентов, заявки, архив, invite‑ссылки, логи, Viewer‑режим.  
- ⚠️ Частично: авто‑отправка invite, Requests без ИИ‑подсказок, логи требуют улучшений.  
- ❌ Будущее: расширенная статистика, 2FA, подтверждение контактов, верификация банковских данных, мульти‑организации, юридическая корректность.
