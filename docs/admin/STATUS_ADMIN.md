## Status реализации

### ✅ Уже внедрено
- **Agents / Requests / Logs**: базовые CRUD‑операции, хранение в `AdminStore`, логирование через `addLog`.
- **Access until**: поле у агента, календарь выбора даты (реализовано). У клиентов срока нет.
- **Requests → Agents**: логика перевода заявки в агента, включая Draft‑агентов.
- **Логи**: аудит всех действий, новые сверху, базовая пагинация и экспорт (CSV/JSON).
- **UI‑валидация**: уникальность boardMemberNumber при добавлении агента.

### ⚠️ Частично реализовано
- **Send link (расширено)**: генерация и регенерация ссылки есть; авто‑отправка, история ссылок, анализ причин повреждений — отсутствуют.
- **Логи**: пагинация работает, но требует доработки (страницы по 10 записей). Экспорт CSV требует улучшения (BOM, кавычки).
- **Requests**: поток заявок реализован, но подсказки ИИ (approve/reject/revise) пока не внедрены.
- **2FA**: заложено в описании программы, но в коде пока нет.
- **Changelog**: логи есть, но отдельного changelog для настроек/ролей нет.

### ❌ Пока отсутствует
- **Расширенная статистика**: метрики логинов, 2FA, активных страниц, SLA, аномалии.
- **Подтверждение контактов** (email/телефон + 2FA).
- **Верификация банковских данных**.
- **Контроль доступа по реестрам организаций** (boards/unions/банки).
- **Юридическая корректность просмотра документов** (согласия, цели обработки, юрисдикции).
- **View clients (модальное окно)**: документы, автозаполнение, обучение ИИ.
- **Конструктор сервисов и мульти‑организации**.
- **Управление доступом через супер админа**: шаблоны ролей, бандлы прав, проверка конфликтов.
