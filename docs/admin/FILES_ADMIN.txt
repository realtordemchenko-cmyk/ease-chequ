## 🗂 Admin Pages Structure

### Layout
- `apps/web/app/admin/layout.tsx` — основной layout админки.  
- `apps/web/app/admin/AdminLayoutClient.tsx` — клиентская часть layout.  
- `apps/web/app/admin/components/Sidebar.tsx` — боковая панель навигации.  
- `apps/web/app/admin/components/Footer.tsx` — нижняя панель.  

### Dashboard
- `apps/web/app/admin/page.tsx` — главная страница админки (Dashboard).  
- `apps/web/app/admin/dashboard/page.tsx` — альтернативный вариант Dashboard.  
- `apps/web/app/admin/dashboard/AdminDashboardPage.tsx` — компонент Dashboard.  

### Agents
- `apps/web/app/admin/agents/page.tsx` — список агентов.  
- `apps/web/app/admin/agents/[id]/page.tsx` — карточка агента + клиенты.  
- `apps/web/app/admin/agents/register/page.tsx` — регистрация нового агента.  
- `apps/web/components/agents/AgentForm.tsx` — форма агента.  
- `apps/web/components/agents/AgentTable.tsx` — таблица агентов.  

### Clients
- `apps/web/app/admin/clients/page.tsx` — список клиентов.  
- `apps/web/app/admin/clients/[id]/page.tsx` — карточка клиента.  

### Requests
- `apps/web/app/admin/requests/page.tsx` — таблица входящих запросов.  
- `apps/web/components/requests/RequestStatusBadge.tsx` — индикатор статуса заявки.  

### Logs
- `apps/web/app/admin/logs/page.tsx` — журнал событий.  
- `apps/web/app/admin/logs/useLogs.ts` — хук для работы с логами.  
- `apps/web/components/logs/LogsFilters.tsx` — фильтры логов.  
- `apps/web/components/logs/LogsTable.tsx` — таблица логов.  
- `apps/web/components/logs/LogsPagination.tsx` — пагинация логов.  

### Settings
- `apps/web/app/admin/settings/page.tsx` — страница настроек.  
- `apps/web/app/admin/settings/SettingsPage.tsx` — компонент настроек.  

### Users
- `apps/web/app/admin/users/page.tsx` — список пользователей.  
- `apps/web/app/admin/users/UsersPage.tsx` — компонент пользователей.
