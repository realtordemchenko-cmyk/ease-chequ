# Ease Chequ — Services Overview

Платформа Ease Chequ построена по модульной архитектуре.  
Каждый сервис (модуль) документируется отдельно и управляется через админ‑панель.

## 📂 Сервисы

- [Prequal‑Rent](./prequal-rent.md) — сервис предквалификации арендаторов (Applicant/Occupant/Guarantor, загрузка документов, ИИ‑проверка, rental application).  
- [Analytics](./analytics.md) — (будущее) сервис аналитики сделок, SLA‑отчётов, статистики агентов.  
- [Banking](./banking.md) — (будущее) сервис интеграции с банками и платёжными системами.  

## 🔑 Принципы
- Модульность: каждый сервис независим, но управляется через админку.  
- Масштабируемость: новые сервисы добавляются без изменения ядра.  
- Безопасность: все документы и данные проходят через единый слой шифрования и логирования.  
- Управляемость: Developer/Admin может включать/отключать сервисы через админ‑панель.
