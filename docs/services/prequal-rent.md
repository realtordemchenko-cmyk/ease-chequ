# Prequal‑Rent Service

Сервис предквалификации арендаторов.  
Позволяет агентам и клиентам безопасно обмениваться документами и получать автоматический анализ.

## 👥 Роли
- **Applicant** — основной заявитель (до 2 на кейс).  
- **Guarantor** — поручитель.  
- **Occupant** — члены семьи/соседи; могут усилить заявку, загрузив документы.  
- **Agent** — управляет кейсом, видит статусы и отчёты ИИ.  
- **Agency** — управляет агентами и подпиской.  

## 📄 Документы
- Employee: Employment Letter, Paystubs, Photo ID, Equifax Report (PDF).  
- Self‑Employed: Bank Statements, NOA, Photo ID, Equifax Report.  
- Both: полный набор.  
- Occupant/Guarantor: могут загружать документы по тем же правилам.  

## 🤖 ИИ‑проверка
- Проверка свежести (Paystub ≤ 14 дней).  
- Проверка полноты (2–3 месяца).  
- Проверка имён (ID vs Credit Report, AKA).  
- Кредитные очки:  
  - 700+ Excellent → Strong application.  
  - 680–699 Attention → рекомендации (депозит, guarantor).  
  - <680 Weak → требуется guarantor.  
- Финансовый анализ: чистый доход – расходы (из кредитного отчёта).  
- Affordability: 30–40% от дохода → рекомендуемая аренда.  

## 📑 Rental Application
- Автозаполнение формы Ontario Rental Application.  
- Возможность редактировать недостающие данные.  
- Итоговый отчёт: рекомендации, риск отказа, affordability.  

## 🔐 Безопасность
- Документы шифруются при загрузке.  
- Агент видит только статусы до Submit.  
- После Submit → документы доступны агенту (decryption).  
- Все действия логируются.  

## 📌 Статус
- ✅ MVP: клиентская анкета, загрузка документов, базовый анализ.  
- ⚠️ Частично: рекомендации по кредитным очкам, анализ Paystubs.  
- ❌ Будущее: авто‑отправка invite, мульти‑организации, SLA‑отчёты.
